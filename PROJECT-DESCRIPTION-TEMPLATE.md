## Controls

{W} -> {Kretanje unapred}  
{S} -> {Kretanje unazad}  
{A} -> {Kretanje ulevo}  
{D} -> {Kretanje udesno}  
{F} -> {Pojavljuje se GUI gde pise trenutna pozicija kamere i moguce menjanje boje Naruto modela}  
{R} -> {Kada se klikne saceka se 1s pa zatim Naruto odskoci i krene da se rotira oko y-ose i treba da se saceka dok se vrati na pocetno mesto kako bi pritiskanje ovog slova opet moglo da radi}  
{N} -> {Promena 2 Naruto modela, kada se klikne Naruto modeli ce se zameniti}
{P} -> {Kada se jednom klikne svetlo se ugasi (padne noc) i kamera ima jedno spot svetlo koje osvetli deo u koji kamera gleda, kada se klikne opet ponovo se vrati prvobitno osvetljenje}
